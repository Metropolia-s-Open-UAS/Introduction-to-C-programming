#### Variables and types in C#
- In computer programs, we often need the ability to remember information. That is achieved with variables, units of memory storage. Variables also carry a type, which defines what kind of information can be stored on them. Operators are symbols that are used to perform operations on operands (variables and/or constants). In this chapter we go through variables, types and operators extensively as their importance cannot be overstated in any programming language.
  
- In the C# programming language, there are two kinds of data types, value types and reference types. The difference between these is that variables of value type directly hold their data whereas variables of reference type store reference to the data. The image below presents these value types.

- Value types can be divided further into simple types, 'enum' types, 'struct' types, 'nullable' value types and 'tuple' value types. Simple types include integers (integrals), character variables, binary and decimal floating-point variables and Boolean variables. C# Reference Types are categorized in the image below.

> Understanding the **Value vs. Reference** distinction is arguably the single most important concept to master in C#—it affects performance, memory, and debugging.


| Concept | Definition | Real-World Analogy |
| :--- | :--- | :--- |
| **Variable** | A named unit of memory storage that holds a value. | A **labeled box** on a shelf. The label is the variable name, and the item inside is the data. |
| **Type** | Defines what kind of data a variable can store (e.g., numbers, text, true/false) and what operations are allowed on it. | A **label on the box** that says "Fragile: Contains Glass" vs "Contains Books". It tells you how to handle it. |
| **Operator** | A symbol (e.g., `+`, `-`, `*`, `==`, `&&`) that performs an operation on operands (variables/literals) to produce a new value. | The **tools** you use to combine or compare the contents of the boxes. |


| Feature | Value Types | Reference Types |
| :--- | :--- | :--- |
| **What they store** | The **actual data** itself (directly). | A **memory address (reference)** that points to the location of the actual data. |
| **Where they live** | Stored on the **Stack** (fast, short-lived memory). | The **reference** lives on the Stack, but the **actual data** lives on the **Heap** (managed memory). |
| **Default value** | `0` for numbers, `false` for bool, `'\0'` for char. | `null` (points to nothing). |
| **Nullability** | By default, *cannot* be `null` (unless made "nullable" with `?` like `int?`). | *Can* be `null`. |
| **Performance** | Faster to access (less indirection). | Slightly slower due to dereferencing (following the pointer) and Garbage Collection overhead. |
| **Assignment behavior** | **Copies the entire value**. Changing one does NOT affect the other. | **Copies the reference**. Both variables point to the **same object** in memory. Changing one affects the other. |


| Category | C# Types | Size / Range | Example |
| :--- | :--- | :--- | :--- |
| **Integral (Integers)** | `sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`, `char` | Varies. `int` = 32-bit (~ -2.1B to 2.1B). `long` = 64-bit (huge). `char` = 16-bit Unicode character. | `int age = 30;` <br> `long population = 8_000_000_000;` <br> `char grade = 'A';` |
| **Binary Floating-Point** | `float` (32-bit), `double` (64-bit) | Used for scientific/math calculations. Precision: `float` ~6-9 digits, `double` ~15-17 digits. | `float pi = 3.14f;` (must add `f` suffix) <br> `double gravity = 9.81;` |
| **Decimal Floating-Point** | `decimal` (128-bit) | Used for **financial/monetary** calculations. Higher precision, smaller range, avoids rounding errors. | `decimal price = 99.95m;` (must add `m` suffix) |
| **Boolean** | `bool` | `true` or `false` (1 byte). | `bool isLoggedIn = true;` |
| **Character** | `char` | A single 16-bit Unicode character (enclosed in **single quotes**). | `char initial = 'J';` |


### Table 4: Common Reference Types

| Type | Description | Example |
| :--- | :--- | :--- |
| **`object`** | The ultimate base class for *all* types (value and reference) in C#. | `object anything = "Hello";` or `object num = 5;` (boxing). |
| **`string`** | A sequence of characters. **Immutable** (cannot be changed once created). | `string name = "Alice";` |
| **`class`** | User-defined blueprints (the core of OOP). | `class Person { public string Name; }` |
| **`interface`** | Defines a contract that classes/structs must implement. | `interface IDrawable { void Draw(); }` |
| **`delegate`** | A type-safe function pointer (used for events and callbacks). | `delegate void Notify(string message);` |
| **`array`** | A fixed-size collection of elements of the same type. | `int[] numbers = new int[10];` |


> **"nullable value types"**. Since value types (like `int`) cannot be `null` by default, C# allows you to make them nullable using `?`:

```csharp
int? age = null; // Now it CAN be null.
if (age.HasValue) {
    Console.WriteLine(age.Value);
}
```
This is incredibly useful when reading from databases or user input where a value might be missing.



```csharp
// VALUE TYPE (int)
int a = 10;
int b = a; // COPIES the value.
b = 20;
Console.WriteLine(a); // Output: 10 (a is unchanged!)

// REFERENCE TYPE (array)
int[] arr1 = new int[] { 1, 2, 3 };
int[] arr2 = arr1; // COPIES the REFERENCE (both point to the same array).
arr2[0] = 999;
Console.WriteLine(arr1[0]); // Output: 999 (arr1 changed too!)
```
