#### Value and reference types


| Type | Description | Range | Suffix | Code Example (Literal) |
| :--- | :--- | :--- | :--- | :--- |
| `byte` | 8-bit unsigned integer | 0 to 255 | *(none)* | `byte b = 255;` |
| `sbyte` | 8-bit signed integer | **-128** to 127 | *(none)* | `sbyte sb = -128;` |
| `short` | 16-bit signed integer | -32,768 to 32,767 | *(none)* | `short s = 30000;` |
| `ushort` | 16-bit unsigned integer | 0 to 65,535 | *(none)* | `ushort us = 60000;` |
| `int` | 32-bit signed integer | -2,147,483,648 to 2,147,483,647 | *(none)* | `int i = 1000000;` *(Default for whole numbers!)* |
| `uint` | 32-bit unsigned integer | 0 to 4,294,967,295 | `u` or `U` | `uint ui = 4000000000u;` |
| `long` | 64-bit signed integer | -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807 | `L` *(use uppercase!)* | `long l = 5000000000L;` |
| `ulong` | 64-bit unsigned integer | 0 to 18,446,744,073,709,551,615 | `ul` or `UL` | `ulong ul = 10000000000000000000ul;` |
| `float` | 32-bit single-precision floating point | ±1.5e−45 to ±3.4e38 | `f` or `F` | `float f = 3.14f;` *(Required!)* |
| `double` | 64-bit double-precision floating point | ±5.0e−324 to ±1.7e308 | `d` or `D` *(optional)* | `double d = 3.14;` *(Default for decimals!)* |
| `decimal` | 128-bit high-precision decimal | ±1.0e-28 to ±7.9e28 | `m` or `M` | `decimal dec = 99.95m;` *(Required for money!)* |
| `char` | 16-bit Unicode character | Any Unicode character (U+0000 to U+FFFF) | *(none)* | `char c = 'A';` *(Single quotes!)* |
| `bool` | Logical boolean | `true` or `false` | *(none)* | `bool flag = true;` |
| `DateTime` | Date and time | 01/01/0001 to 12/31/9999 | *(none)* | `DateTime dt = DateTime.Now;` |


- **`int` is the default** for whole numbers. If you write `100`, the compiler assumes it's an `int`.  
- **`double` is the default** for numbers with a decimal. If you write `3.14`, the compiler assumes it's a `double`.  
- **You MUST use suffixes** for `float` (`f`), `decimal` (`m`), `uint` (`u`), and `long` (`L`).  
- **NEVER use lowercase `l`** for `long`—it looks exactly like the number `1` (one)! Always use uppercase `L` (e.g., `100L`). This is a classic C# rookie mistake that causes confusing bugs.
- 
> Reference Types, keywords class, interface and delegate are used to declare reference types. C# has also the following built-in reference types: dynamic, object, string.



**The most common reference types in C# are:**

| Reference Type | Keyword / Syntax | Description |
| :--- | :--- | :--- |
| **Class** | `class` | The blueprint for objects (e.g., `class Person { }`). |
| **Interface** | `interface` | A contract that classes must follow (e.g., `interface IShape { }`). |
| **Delegate** | `delegate` | A type-safe function pointer (e.g., `delegate void MyHandler();`). |
| **String** | `string` | *(Alias for `System.String`)*—a sequence of characters. **Immutable**. |
| **Object** | `object` | *(Alias for `System.Object`)*—the ultimate base class of *everything*. |
| **Array** | `type[]` | A collection of items (e.g., `int[] numbers = new int[10];`). |
