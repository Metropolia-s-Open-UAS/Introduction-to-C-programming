#### Lists
- C# provides a List collection class for strongly typed list of objects which can be accessed by an index.
-  The class also provides simple yet powerful methods to search, sort and manipulate lists.
-  The List<T> class is contained with the `System.Collections.Generic` namespace.
.

#### `List<T>` – Overview

| Aspect | Details |
| :--- | :--- |
| **Namespace** | `System.Collections.Generic` |
| **Dynamic Size** | Automatically grows and shrinks as elements are added/removed |
| **Indexing** | Zero-based (like arrays) |
| **Type Safety** | Strongly typed—only accepts elements of type `T` |
| **Performance** | Slightly slower than arrays, but much more flexible |
| **Underlying Implementation** | Uses an array internally; resizes automatically when needed |

#### Table 1: Common `List<T>` Methods

| Method | Description | Example |
| :--- | :--- | :--- |
| **`Add(T item)`** | Adds an item to the end of the list. | `cities.Add("New York");` |
| **`AddRange(IEnumerable<T> collection)`** | Adds multiple items to the end of the list. | `cities.AddRange(new[] { "London", "Paris" });` |
| **`Insert(int index, T item)`** | Inserts an item at a specific index. | `cities.Insert(0, "Tokyo");` |
| **`InsertRange(int index, IEnumerable<T> collection)`** | Inserts multiple items at a specific index. | `cities.InsertRange(1, new[] { "Berlin", "Madrid" });` |
| **`Remove(T item)`** | Removes the first occurrence of a specific item. | `cities.Remove("Paris");` |
| **`RemoveAt(int index)`** | Removes the item at a specific index. | `cities.RemoveAt(0);` |
| **`RemoveAll(Predicate<T> match)`** | Removes all items that match a condition. | `cities.RemoveAll(c => c.StartsWith("M"));` |
| **`Clear()`** | Removes all elements from the list. | `cities.Clear();` |
| **`Contains(T item)`** | Returns `true` if the item exists in the list. | `bool has = cities.Contains("London");` |
| **`IndexOf(T item)`** | Returns the index of the first occurrence of an item. | `int idx = cities.IndexOf("Paris");` |
| **`LastIndexOf(T item)`** | Returns the index of the last occurrence of an item. | `int idx = cities.LastIndexOf("Paris");` |
| **`Sort()`** | Sorts the list in ascending order. | `cities.Sort();` |
| **`Reverse()`** | Reverses the order of elements in the list. | `cities.Reverse();` |
| **`ToArray()`** | Converts the list to an array. | `string[] arr = cities.ToArray();` |
| **`Find(Predicate<T> match)`** | Returns the first element that matches a condition. | `string city = cities.Find(c => c.StartsWith("L"));` |
| **`FindAll(Predicate<T> match)`** | Returns all elements that match a condition. | `List<string> results = cities.FindAll(c => c.Length > 5);` |
| **`Exists(Predicate<T> match)`** | Returns `true` if any element matches a condition. | `bool exists = cities.Exists(c => c == "Paris");` |
| **`TrueForAll(Predicate<T> match)`** | Returns `true` if all elements match a condition. | `bool all = cities.TrueForAll(c => c.Length > 0);` |
| **`ForEach(Action<T> action)`** | Performs an action on each element. | `cities.ForEach(c => Console.WriteLine(c));` |

#### Basic `List<T>` Example (Based on Your Image)

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // Declaration and initialization
        List<string> cities = new List<string>();
        
        // Adding items
        cities.Add("New York");
        cities.Add("London");
        cities.Add("Paris");
        cities.Add("Tokyo");
        
        Console.WriteLine("Cities:");
        foreach (string city in cities)
        {
            Console.WriteLine($"  {city}");
        }
        
        // Insert at a specific index
        cities.Insert(1, "Berlin");
        Console.WriteLine("\nAfter inserting Berlin at index 1:");
        foreach (string city in cities)
        {
            Console.WriteLine($"  {city}");
        }
        
        // Remove an item
        cities.Remove("Paris");
        Console.WriteLine("\nAfter removing Paris:");
        foreach (string city in cities)
        {
            Console.WriteLine($"  {city}");
        }
        
        // Remove at index
        cities.RemoveAt(0);
        Console.WriteLine("\nAfter removing at index 0:");
        foreach (string city in cities)
        {
            Console.WriteLine($"  {city}");
        }
        
        // Check if exists
        bool hasLondon = cities.Contains("London");
        Console.WriteLine($"\nContains London? {hasLondon}");
    }
}
```

**Output:**
```
Cities:
  New York
  London
  Paris
  Tokyo

After inserting Berlin at index 1:
  New York
  Berlin
  London
  Paris
  Tokyo

After removing Paris:
  New York
  Berlin
  London
  Tokyo

After removing at index 0:
  Berlin
  London
  Tokyo

Contains London? True
```

#### Accessing Elements in a List

```csharp
List<int> numbers = new List<int> { 10, 20, 30, 40, 50 };

// Access by index
Console.WriteLine($"First: {numbers[0]}"); // Output: 10
Console.WriteLine($"Last: {numbers[numbers.Count - 1]}"); // Output: 50

// Modify by index
numbers[0] = 99;
Console.WriteLine($"Modified first: {numbers[0]}"); // Output: 99

// Loop through all elements
foreach (int num in numbers)
{
    Console.Write(num + " ");
}
// Output: 99 20 30 40 50
```

#### `List<T>` vs `Array` – When to Use Which

| Scenario | Recommended | Why |
| :--- | :--- | :--- |
| **Fixed size known at compile time** | Array | More efficient, less overhead. |
| **Dynamic size (unknown number of elements)** | `List<T>` | Automatically grows/shrinks. |
| **Frequent insertion/deletion at the end** | `List<T>` | Efficient (amortized O(1) for add). |
| **Frequent insertion/deletion in the middle** | `LinkedList<T>` | `List<T>` is O(n) for middle operations. |
| **Need to access by index frequently** | Both | Both support index access. |
| **Need to pass to a method expecting an array** | Array or `ToArray()` | Use `List<T>` and call `ToArray()` when needed. |

#### Advanced: Using `Predicate<T>` with `Find` and `FindAll`

A `Predicate<T>` is a delegate that represents a method that checks a condition:

```csharp
List<int> numbers = new List<int> { 5, 10, 15, 20, 25, 30, 35 };

// Find the first number greater than 20
int first = numbers.Find(n => n > 20);
Console.WriteLine($"First > 20: {first}"); // Output: 25

// Find all numbers between 10 and 30
List<int> filtered = numbers.FindAll(n => n >= 10 && n <= 30);
Console.WriteLine($"Between 10 and 30: {string.Join(", ", filtered)}");
// Output: 10, 15, 20, 25, 30

// Check if any number is greater than 50
bool exists = numbers.Exists(n => n > 50);
Console.WriteLine($"Exists > 50: {exists}"); // Output: False

// Check if all numbers are positive
bool allPositive = numbers.TrueForAll(n => n > 0);
Console.WriteLine($"All positive: {allPositive}"); // Output: True
```

#### Sorting and Reversing

```csharp
List<string> names = new List<string> { "Zara", "Alice", "Bob", "Charlie" };

// Sort ascending
names.Sort();
Console.WriteLine($"Sorted: {string.Join(", ", names)}");
// Output: Alice, Bob, Charlie, Zara

// Reverse
names.Reverse();
Console.WriteLine($"Reversed: {string.Join(", ", names)}");
// Output: Zara, Charlie, Bob, Alice

// Custom sort (by length)
names.Sort((a, b) => a.Length.CompareTo(b.Length));
Console.WriteLine($"Sorted by length: {string.Join(", ", names)}");
// Output: Bob, Zara, Alice, Charlie
```

#### Complete Example: Managing a To-Do List

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        List<string> tasks = new List<string>();
        bool running = true;
        
        while (running)
        {
            Console.WriteLine("\n--- To-Do List ---");
            Console.WriteLine("1. Add task");
            Console.WriteLine("2. Remove task");
            Console.WriteLine("3. View all tasks");
            Console.WriteLine("4. Exit");
            Console.Write("Choose an option: ");
            
            string choice = Console.ReadLine();
            
            switch (choice)
            {
                case "1":
                    Console.Write("Enter task: ");
                    string task = Console.ReadLine();
                    tasks.Add(task);
                    Console.WriteLine($"Added: {task}");
                    break;
                    
                case "2":
                    Console.Write("Enter task to remove: ");
                    string remove = Console.ReadLine();
                    if (tasks.Remove(remove))
                        Console.WriteLine($"Removed: {remove}");
                    else
                        Console.WriteLine("Task not found!");
                    break;
                    
                case "3":
                    if (tasks.Count == 0)
                        Console.WriteLine("No tasks!");
                    else
                    {
                        Console.WriteLine("Tasks:");
                        for (int i = 0; i < tasks.Count; i++)
                        {
                            Console.WriteLine($"  {i + 1}. {tasks[i]}");
                        }
                    }
                    break;
                    
                case "4":
                    running = false;
                    break;
                    
                default:
                    Console.WriteLine("Invalid option!");
                    break;
            }
        }
    }
}
```

#### Common Mistakes & Best Practices

|  Bad Code |  Good Code | Why |
| :--- | :--- | :--- |
| `List<int> numbers = new List<int>();` <br> `numbers[0] = 10;` | `numbers.Add(10);` | You can't assign to an index that doesn't exist. |
| `foreach (int n in list) { list.Add(n * 2); }` | Use a `for` loop or create a new list. | Modifying a list while iterating over it throws an exception. |
| `list.RemoveAll(n => n > 5);` | Use `RemoveAll` with a predicate. | `Remove` only removes one element; `RemoveAll` removes all matching. |
| `if (list.Contains(item)) list.Remove(item);` | `list.Remove(item);` | `Remove` already checks for existence and returns a boolean. |

5. `RemoveAt(1)` → `[0, 2, 4, 5, 6]`
