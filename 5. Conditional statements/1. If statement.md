#### Table 1: Decision-Making Statements at a Glance

| Statement | Use Case | Syntax |
| :--- | :--- | :--- |
| **`if`** | Execute code if a condition is `true`. | `if (condition) { // code }` |
| **`if-else`** | Execute one block if `true`, another if `false`. | `if (condition) { } else { }` |
| **`else if`** | Check multiple, mutually exclusive conditions. | `if (a) { } else if (b) { } else { }` |
| **`switch`** | Compare a single variable against multiple constant values. | `switch (value) { case 1: break; case 2: break; }` |

#### Table 2: The `if` Statement – Breakdown

Based on your example (where `condition = true`):

| Line Concept | Code | Explanation |
| :--- | :--- | :--- |
| **Boolean variable** | `bool condition = true;` | Declares a variable that stores either `true` or `false`. |
| **The `if` check** | `if (condition)` | Evaluates the expression inside parentheses. If it's `true`, execution enters the body. |
| **Body of `if`** | `{ Console.WriteLine("Condition is true!"); }` | The code block that runs *only* when `condition` is `true`. |
| **What happens if `false`** | Program skips the `if` body and continues | The program resumes execution at the line immediately after the closing `}` of the `if` block. |

**Important:** The parentheses `()` after `if` are **required**. The condition inside must evaluate to a `bool` (either `true` or `false`).

#### Table 3: `if-else` vs `else if` – The Difference

| Code Structure | When It Runs | Example Scenario |
| :--- | :--- | :--- |
| **`if` alone** | Only the `if` block runs if `true`. Nothing runs if `false`. | "If the user is admin, show the admin panel." |
| **`if-else`** | `if` block runs on `true`. `else` block runs on `false`. | "If the user is admin, show admin panel. Otherwise, show user dashboard." |
| **`if-else if-else`** | Checks multiple conditions in order. Stops at the first `true`. The final `else` runs if *none* are `true`. | "If score >= 90, grade A. Else if score >= 80, grade B. Else, grade C." |


####  Multiple Conditions with `else if`

```csharp
int score = 85;

if (score >= 90)
{
    Console.WriteLine("Grade: A");
}
else if (score >= 80)
{
    Console.WriteLine("Grade: B");
}
else if (score >= 70)
{
    Console.WriteLine("Grade: C");
}
else
{
    Console.WriteLine("Grade: F");
}
```
**Output:** `"Grade: B"` (stops at the first true condition).



####  Critical Nuances & Best Practices

| Concept | Explanation | Example |
| :--- | :--- | :--- |
| **Curly Braces `{ }`** | For single-line `if` statements, braces are optional, but **always use them** to avoid bugs and improve readability. | `if (x > 5) Console.WriteLine("Hi");` (works but avoid) vs `if (x > 5) { Console.WriteLine("Hi"); }` (preferred). |
| **Common Bug: `=` vs `==`** | Using `=` instead of `==` inside an `if` condition will *assign* instead of *compare*—and usually compiles! | `if (x = 5)` ❌ (assigns 5 to x, condition always true) <br> `if (x == 5)` ✅ (checks equality). |
| **Boolean Variable Shortcut** | If a variable is already a `bool`, you don't need to compare it to `true` or `false`. | Instead of `if (isLoggedIn == true)`, just write `if (isLoggedIn)`. For false: `if (!isLoggedIn)`. |
| **Nested `if` Statements** | You can nest `if` statements inside each other, but beware of "arrow code" (deep nesting). Use early returns or combine conditions with `&&`/`||` when possible. | `if (a > 0) { if (b > 0) { Console.WriteLine("Both positive"); } }` |
