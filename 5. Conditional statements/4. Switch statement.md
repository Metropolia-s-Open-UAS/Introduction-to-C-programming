#### Switch statement
- The switch statement has some functional similarities with if statement. However, a switch statement requires each case with a single value, unlike if-statement which can accept also value ranges. Every switch case includes its own block of code, which is executed if the value matches. If none of the cases match, the optional default block is executed.

- The match expression can be any non-null expression, for example a char, a string, a boolean value, an integral value (e.g. int or long) or an enum value. In the example, an integral value is used.

> C# programming language does not allow the execution to move from one switch-case section to the next. That can be prevented using a break or goto jump statement (more on jump statements in chapter 6) or a return statement.



#### The `switch` Statement – Anatomy

Based on your description (using an integral value):

```csharp
int day = 3;

switch (day)
{
    case 1:
        Console.WriteLine("Monday");
        break;
    case 2:
        Console.WriteLine("Tuesday");
        break;
    case 3:
        Console.WriteLine("Wednesday");
        break;
    case 4:
        Console.WriteLine("Thursday");
        break;
    case 5:
        Console.WriteLine("Friday");
        break;
    case 6:
        Console.WriteLine("Saturday");
        break;
    case 7:
        Console.WriteLine("Sunday");
        break;
    default:
        Console.WriteLine("Invalid day number");
        break;
}
```

**Output:** `"Wednesday"` (because `day = 3` matches `case 3`).


#### Table 1: `if-else if` vs `switch` – Key Differences

| Feature | `if-else if` | `switch` |
| :--- | :--- | :--- |
| **Condition type** | Can evaluate **any Boolean expression** (e.g., `score >= 90`, `name == "Alice" && age > 18`). | Can only compare against **specific constant values** (e.g., `1`, `"Monday"`, `Color.Red`). |
| **Ranges** | ✅ Supports ranges naturally (e.g., `score >= 80`). | ❌ Doesn't support ranges directly (unless using C# 9.0+ relational patterns). |
| **Multiple values** | Use `||` (OR) to combine. | Can stack cases (e.g., `case 1:` `case 2:`). |
| **Fall-through** | N/A (each branch is independent). | ❌ **Not allowed** by default. Each case must end with `break`, `return`, or `goto`. |
| **Readability** | Can become messy with many conditions. | Cleaner for many exact-value checks. |


#### Critical Rule: No Fall-Through (C# vs C/C++)

Your text correctly notes that C# **does not allow** execution to "fall through" from one case to the next. This is a deliberate design choice to prevent the classic **"missing break" bug** that plagues C/C++ code.

**In C/C++ (dangerous):**
```csharp
switch (x)
{
    case 1:
        Console.WriteLine("One");
        // FALLS THROUGH to case 2! (Bug waiting to happen)
    case 2:
        Console.WriteLine("Two");
        break;
}
```

**In C# (safe and explicit):**
```csharp
switch (x)
{
    case 1:
        Console.WriteLine("One");
        // break; // If omitted, compiler ERROR!
        break;     // REQUIRED!
    case 2:
        Console.WriteLine("Two");
        break;
}
```

| Termination Method | When to Use |
| :--- | :--- |
| `break;` | Exit the `switch` and continue with the next statement after the closing `}`. |
| `return;` | Exit the entire method (works only if the method returns `void`). |
| `return value;` | Exit the method and return a value. |
| `goto case 3;` | Jump to another case (rare, but available). |
| `throw new Exception();` | Throw an exception (and exit the `switch`). |


#### Stacked Cases – Sharing Code

When multiple cases should execute the **same code**, you can stack them:

```csharp
string dayType;
switch (day)
{
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        dayType = "Weekday";
        break;
    case 6:
    case 7:
        dayType = "Weekend";
        break;
    default:
        dayType = "Invalid";
        break;
}
Console.WriteLine(dayType); // "Weekday" for day 1-5, "Weekend" for 6-7
```

**Note:** Even though `case 1:`, `case 2:`, etc., are stacked, the code block only runs once when a match is found.

#### Modern C# Enhancements (C# 8.0+ and C# 9.0+)

Your lesson covers the classic `switch`. Here are the **powerful modern additions** you'll encounter in real-world code:

#### 1. **Switch Expressions** (C# 8.0) – A more concise syntax

```csharp
string dayType = day switch
{
    1 => "Monday",
    2 => "Tuesday",
    3 => "Wednesday",
    4 => "Thursday",
    5 => "Friday",
    6 => "Saturday",
    7 => "Sunday",
    _ => "Invalid"  // _ is the default (like else)
};
Console.WriteLine(dayType); // "Wednesday"
```

**Benefits:** No `break` statements, more readable, and returns a value directly.

#### 2. **Relational Patterns** (C# 9.0) – Ranges in `switch`!

Now `switch` can handle ranges too (previously only `if-else` could):

```csharp
int score = 85;
string grade = score switch
{
    >= 90 => "A",
    >= 80 => "B",
    >= 70 => "C",
    >= 60 => "D",
    < 60 => "F"
};
Console.WriteLine(grade); // "B"
```

This is a **game-changer**—now you can use `switch` for both exact matches AND ranges!

---

#### 3. **Pattern Matching** – Type checks in `switch`

```csharp
object obj = "Hello, World!";

string result = obj switch
{
    int i => $"It's an integer: {i}",
    string s => $"It's a string: {s}",
    null => "It's null!",
    _ => "Unknown type"
};
Console.WriteLine(result); // "It's a string: Hello, World!"
```

#### Common Beginner Mistakes

| ❌ Bad Code | ✅ Good Code | Why |
| :--- | :--- | :--- |
| `case 1: Console.WriteLine("One");` <br> `case 2: Console.WriteLine("Two"); break;` | `case 1: Console.WriteLine("One"); break;` <br> `case 2: Console.WriteLine("Two"); break;` | Missing `break` causes a **compiler error** in C#. You must explicitly terminate each case. |
| `case 1, 2:` (trying to use comma-separated cases) | `case 1:` <br> `case 2:` | In classic `switch`, commas aren't allowed. Use stacked cases instead. |
| `switch (x) { case 1: ... }` (forgetting `default`) | `switch (x) { case 1: ... default: ... }` | Always include a `default` case to handle unexpected values—it's a best practice! |


#### Connecting to Your Previous Programs

Now you can handle multiple command-line arguments elegantly:

```csharp
static void Main(string[] args)
{
    if (args.Length == 0)
    {
        Console.WriteLine("No argument provided.");
        return;
    }

    switch (args[0].ToLower())
    {
        case "--help":
        case "-h":
            Console.WriteLine("Usage: Program.exe <name>");
            break;
        case "--version":
        case "-v":
            Console.WriteLine("Version 1.0");
            break;
        default:
            Console.WriteLine($"Hello, {args[0]}!");
            break;
    }
}
```

#### Summary Table: When to Use What

| Scenario | Best Choice |
| :--- | :--- |
| Checking exact values (e.g., `day`, `command`, `status code`) | **`switch`** or **Switch Expression** (C# 8.0+) |
| Checking ranges (e.g., `score >= 80`, `age between 13 and 19`) | **`if-else if`** (or **Relational Patterns** in C# 9.0+) |
| Complex conditions with multiple variables (e.g., `age > 18 && country == "US"`) | **`if-else if`** |
| Type checking (e.g., `if (obj is string)`) | **Pattern Matching** in `switch` (C# 7.0+) |
