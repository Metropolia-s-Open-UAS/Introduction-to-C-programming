#### Do While
- The do-while statement executes a statement or a block of statements while a specified condition (expression) evaluates to true. Do-while statement executes at least once, as the condition is evaluated after the statement block. The syntax of Do-while statement is the following:
```csharp
do
{
      /* statements */
} while (condition)
```
> As with `while` statement, the execution of the statement **stops** either when the *condition does not evaluate to true* or a **jump** statement (`break`,`goto`, `return` or `throw`) is used. While executing the loop it is also possible to skip directly to the *condition evaluation with continue statement*.
Perfect! You've now covered the **`do-while`** loop, which is the **"guaranteed execution"** sibling of the `while` loop. The key difference is that `do-while` always executes **at least once**, making it ideal for scenarios where you need to run an action before checking a condition.


```csharp
int counter = 0;

do
{
    Console.WriteLine($"Counter: {counter}");
    counter++;
} while (counter < 5);

Console.WriteLine("Loop finished!");
```

**Output:**
```
Counter: 0
Counter: 1
Counter: 2
Counter: 3
Counter: 4
Loop finished!
```

| Feature | `while` | `do-while` |
| :--- | :--- | :--- |
| **Condition Check** | At the **beginning** (before the body). | At the **end** (after the body). |
| **Minimum Executions** | **Zero** (if condition is initially `false`). | **At least once** (condition is checked after the first run). |
| **Syntax** | `while (condition) { }` | `do { } while (condition);` |
| **Semicolon** | No semicolon after the closing brace. | **Requires a semicolon** after `while (condition);` |

```csharp
int i = 0;                     // Step 1: Initialize

do                             // Step 2: Enter the loop body (no condition check yet!)
{                              // Step 3: Execute the body
    Console.WriteLine(i);      // Step 4: Print
    i++;                       // Step 5: Increment (i becomes 1)
}                              // Step 6: Check condition at the END
while (i < 3);                 // Step 7: If true, go back to Step 2. If false, exit.

// The body always runs at least once, even if the condition is false!
```


#### Best Practices for `do-while`

| Scenario | Why `do-while` is the right choice |
| :--- | :--- |
| **Menu systems** | You always want to display the menu at least once. |
| **Input validation** | You need to prompt the user at least once. |
| **Game loops** | The game should run at least one frame before checking exit conditions. |
| **Initialization then check** | You need to perform an action before evaluating the condition. |


####  Critical Rules & Common Mistakes

|  Mistake |  Correct | Why |
| :--- | :--- | :--- |
| `do { } while (x < 10)` (missing semicolon) | `do { } while (x < 10);` | The semicolon is **required** after the `while` condition in `do-while`. This is a common syntax error! |
| `int x = 10; do { x++; } while (x < 5);` | The body runs **once** even though `x < 5` is false. | This is the intended behavior—not a bug. But be aware of it! |
| `do { break; } while (true);` | Works—`break` exits the loop immediately. | `break` works the same way in `do-while` as it does in `while`. |


####  When to Use `do-while` vs `while` (Decision Table)

| Requirement | Recommended Loop | Example |
| :--- | :--- | :--- |
| The action **must run at least once** before checking the condition. | **`do-while`** | Display a menu, prompt for input. |
| The action **should only run if the condition is true** (may run zero times). | **`while`** | Processing data that might already be empty. |
| The number of iterations is **known in advance** (counter-controlled). | **`for`** | Iterating through an array of known size. |
| Iterating over a **collection/enumerable** (e.g., list, array). | **`foreach`** | Processing each item in a list. |


#### Summary: All Loop Types at a Glance

| Loop Type | Condition Check | Minimum Executions | Best Used For |
| :--- | :--- | :--- | :--- |
| **`while`** | Beginning | 0 | When you don't know if the condition will be true initially. |
| **`do-while`** | End | **1** | When you need to execute the body at least once (e.g., prompts, menus). |
| **`for`** | Beginning | 0 | When you know the exact number of iterations (counter-controlled). |
| **`foreach`** | Beginning | 0 | When iterating over collections (lists, arrays). |
