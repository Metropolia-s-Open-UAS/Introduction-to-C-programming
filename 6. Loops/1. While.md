#### While 
- `Loop` statements are basic yet powerful statements to repeat instructions until a specified condition (`expression`) is met.
-  In this chapter we learn about `while`, `do-while`, `for` and `foreach` loops and jump statements.
>   The while statement executes a statement or a block of statements while a specified condition evaluates to true. A while loop executes zero or more times as the condition is evaluated before the statements. The syntax of a while statement is as follows:
```csharp
while(condition){
/*
statments
*/
}
```
- The execution of the statement stops either when the condition does not evaluate to true or a jump statement (`break`,` goto`, `return` or `throw`) is used. While executing the loop it is also possible to skip directly to the condition evaluation with continue statement.

```csharp
int counter = 0;

while (counter < 5)
{
    Console.WriteLine($"Counter: {counter}");
    counter++; // Increment to avoid infinite loop!
}

Console.WriteLine("Loop finished!");
```

**Output:**
```
Counter: 0
Counter: 1
Counter: 2
Counter: 3
Counter: 4
Loop finished!
```

| Characteristic | Explanation |
| :--- | :--- |
| **Condition checked** | At the **start** of each iteration (before executing the loop body). |
| **Minimum executions** | **Zero**—if the condition is initially `false`, the body never runs. |
| **Termination** | Stops when the condition becomes `false`, or when a jump statement (`break`, `return`, `goto`, `throw`) is encountered. |
| **Skipping to next iteration** | Use `continue;` to jump directly to the condition check (skipping the rest of the body). |
| **Risk** | If the condition never becomes `false`, you get an **infinite loop** (program hangs). |

#### Execution Flow (Step-by-Step)

```csharp
int i = 0;                     // Step 1: Initialize

while (i < 3)                  // Step 2: Check condition (true)
{                              // Step 3: Enter the loop body
    Console.WriteLine(i);      // Step 4: Print
    i++;                       // Step 5: Increment (i becomes 1)
}                              // Step 6: Jump back to Step 2 (check again)

// Repeat Steps 2-6 until condition becomes false (i == 3)
// Then exit the loop
```

**Common infinite loop patterns to avoid:**
|  Bug |  Fix |
| :--- | :--- |
| `while (true) { }` (no break) | `while (true) { if (condition) break; }` |
| `while (x > 0) { /* x never changes */ }` | Ensure `x` is updated inside the loop. |
| `while (i != 10) { i += 2; }` (i jumps from 8 to 10?) | Use `<`/`>` instead of `!=` to avoid skipping the exact value. |


####  The `do-while` Loop (A Quick Preview)

| Loop Type | Condition Check | Minimum Executions |
| :--- | :--- | :--- |
| **`while`** | At the **beginning** (before the body). | **Zero** times (if condition is initially `false`). |
| **`do-while`** | At the **end** (after the body). | **At least once** (body runs before checking the condition). |

**Example:**
```csharp
int i = 10;
do
{
    Console.WriteLine("This runs once, even though i > 5!");
    i++;
} while (i < 5); // Condition is false, but body already ran once.
```

####  Real-World Use Cases for `while`

| Scenario | Why `while`? |
| :--- | :--- |
| **Reading user input until valid** | Keep prompting until the user enters valid data. |
| **Processing a file until end** | Read lines until `null` (end of file). |
| **Game loops** | Run the game logic until the player quits. |
| **Waiting for a condition** | Keep checking until a resource becomes available (e.g., network connection). |

**Example – Input Validation:**
```csharp
string input = "";
while (string.IsNullOrEmpty(input))
{
    Console.Write("Please enter your name: ");
    input = Console.ReadLine();
    if (string.IsNullOrEmpty(input))
    {
        Console.WriteLine("Name cannot be empty! Try again.");
    }
}
Console.WriteLine($"Hello, {input}!");
```


#### Best Practices & Common Mistakes

| Best Practice | Why? |
| :--- | :--- |
| **Always ensure the condition changes** | Prevents infinite loops. |
| **Use `break` for early termination** | Simpler than complex conditions. |
| **Avoid `while (true)` unless necessary** | Usually indicates poor design—try to use a proper condition. |
| **Use `do-while` when you need at least one execution** | For example, menu systems where you always display the menu once. |
