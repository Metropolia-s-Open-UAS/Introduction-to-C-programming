#### For
- The For statement executes a statement or a group of statements while a specified condition (expression) evaluates to true. For statement differs from while and do-while statements with optional initializer and iterator. The syntax of for statement is:
```csharp
for (initializer; condition, iterator)
{
      /* statements */
}
```
1. **The initializer** is zero or more statement expressions separated by commas. Note that the initializer variables can only be accessed inside the loop. In the following example, the initializer declares integral type variable I and assigns it with value 0.
2. **The condition** section is a Boolean expression and is evaluated before every iteration. The condition section determines if the loop should terminate. In the example, the loop is executed until variable i is equal or greater than 5.
3. **The iterator** section is executed after every loop. It can contain zero or more of the following: assignment statement, invocation of a method, prefix/postfix increment/decrement expressions (--i, ++i, i--, i++), creation of an object by using the new operator or await expression. In the example, we increment the value of variable i by one after every loop.

```csharp
for (int i = 0; i < 5; i++)
{
    Console.WriteLine($"Iteration: {i}");
}
```

**Output:**
```
Iteration: 0
Iteration: 1
Iteration: 2
Iteration: 3
Iteration: 4
```

#### The `for` Loop – Anatomy

The `for` loop has **three main sections**, each serving a specific purpose:

| Section | Purpose | When It Executes | Example |
| :--- | :--- | :--- | :--- |
| **Initializer** | Declares and/or initializes the loop variable(s). | **Once**, at the very beginning (before the first iteration). | `int i = 0;` |
| **Condition** | The Boolean expression that determines if the loop should continue. | **Before every iteration** (if `true`, run the body; if `false`, exit). | `i < 5;` |
| **Iterator** | Updates the loop variable(s) after each iteration. | **After each iteration** (when the body completes). | `i++` |

**Note:** All three sections are **optional**. You can write `for (;;)` to create an infinite loop!

#### Execution Flow (Step-by-Step)

```csharp
// Step 1: INITIALIZER runs once (int i = 0)
// Step 2: CONDITION checked (i < 5) → true → enter body
// Step 3: BODY executes
// Step 4: ITERATOR runs (i++)
// Step 5: Go back to Step 2 (condition check)
// Repeat until condition becomes false
// Step 6: Exit loop when condition is false

for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
```

| Section | Syntax | Allowed Content | Example |
| :--- | :--- | :--- | :--- |
| **Initializer** | `initializer;` | Declaration of a new variable, assignment, method call (rare) | `int i = 0;` |
| **Condition** | `condition;` | Any Boolean expression that returns `true` or `false` | `i < 5;` |
| **Iterator** | `iterator;` | Increment/decrement, assignment, method invocation, object creation | `i++` |

#### Multiple Variables in `for` Loops

The `for` loop supports **multiple initializers** and **multiple iterators**:

```csharp
for (int i = 0, j = 10; i < j; i++, j--)
{
    Console.WriteLine($"i = {i}, j = {j}");
}
```

**Output:**
```
i = 0, j = 10
i = 1, j = 9
i = 2, j = 8
i = 3, j = 7
i = 4, j = 6
```

**Rules for multiple variables:**
- Separate initializers with a comma `,`.
- Separate iterators with a comma `,`.
- Only **one condition** is allowed.


#### Advanced `for` Loop Patterns

| Pattern | Example | Use Case |
| :--- | :--- | :--- |
| **Counting Down** | `for (int i = 10; i > 0; i--)` | Countdown timer, reverse iteration. |
| **Step Size > 1** | `for (int i = 0; i < 100; i += 10)` | Iterating with a custom step (e.g., every 10th element). |
| **Infinite Loop** | `for (;;) { }` | Game loop, server process that runs continuously until stopped. |
| **No Body (Empty)** | `for (int i = 0; i < 100; i++) ;` | Delaying execution or busy-waiting. |
| **Complex Condition** | `for (int i = 0; i < array.Length && !found; i++)` | Combining conditions with logical operators. |



#### Common Mistakes & Best Practices

|  Bad Code |  Good Code | Why |
| :--- | :--- | :--- |
| `for (int i = 0; i < 5; i++); { Console.WriteLine(i); }` | `for (int i = 0; i < 5; i++) { Console.WriteLine(i); }` | The semicolon after the `for` statement ends the loop prematurely! The block that follows runs **after** the loop, causing `i` to be out of scope (compiler error) or just running once. |
| `for (int i = 0; i <= 10; i++)` (using `<=` instead of `<`) | `for (int i = 0; i < 11; i++)` | Both work, but `<` is more idiomatic for zero-based loops and avoids off-by-one errors. |
| `for (int i = 0; i < array.Length; i--` (decrementing when counting up) | `for (int i = 0; i < array.Length; i++)` | If you decrement `i` but expect it to increase, you'll get an infinite loop or out-of-range access. |
| **Forgetting to update the iterator** | Always ensure the iterator is updated | Without an iterator, the condition might never become `false`, causing an infinite loop. |


#### Comparison: `for` vs `while` vs `do-while`

| Feature | `for` | `while` | `do-while` |
| :--- | :--- | :--- | :--- |
| **When condition is checked** | Beginning | Beginning | End |
| **Minimum executions** | 0 | 0 | 1 |
| **Best for** | Known number of iterations, counter-controlled loops | Unknown number of iterations | Guaranteed at least one execution |
| **Initializer** | ✅ Built-in | ❌ Must declare outside | ❌ Must declare outside |
| **Iterator** | ✅ Built-in | ❌ Must manage manually | ❌ Must manage manually |
| **Variable scope** | Limited to loop | Depends on declaration | Depends on declaration |
