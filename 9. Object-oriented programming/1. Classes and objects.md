#### Classes and objects
- In this chapter we cover another fundamental topic, object-oriented programming. We learn how to define classes and instantiate objects from them.
-  We also learn how to define `class fields`, `constructors`, `methods` and `properties`.
-  **Object-oriented programming** is a programming paradigm based on `objects` having both `data` and `methods`.
  - The Classes act as blueprints for objects as in the real world
    > for example, an object instantiated from a building Class has a color, a height and a count of a doors and so on. So far on this course we have had only one class and method, the Main method.
- [ ] A class can be declared by using the class keyword followed by a unique identifier:
```csharp
public class Building
{
    /* fields, properties, methods */
}
```
- [ ] `public` is the **access modifier** in the declaration and means that anyone can create instances of the class.
- [ ] The class naming convention should follow `PascalCase`,
> meaning capitalizing the first letter of each word.
- [ ] As mentioned, objects are entities based on class.
- [ ] Objects are created using the new keyword followed by the class name.
- [ ] A reference to an object is returned.
```csharp
Building object1 = new Building();

```
