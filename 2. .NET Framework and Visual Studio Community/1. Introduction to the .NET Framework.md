#### Introduction to the .NET Framework
- In this chapter we learn about the .NET Framework and the IDE of choice on this course, Microsoft Visual Studio Community.
- Alternative IDE’s are also available in case you want to explore different software options.
- These include **MonoDevelop** and **Xamarin Studio** but they are not covered in this course.
> .NET Framework is a software development framework for building and running applications on Windows. It consists of tools, programming languages and libraries, which enables one to build different types of applications. See the following image for the architecture of the .NET Framework.

<img src="https://github.com/Metropolia-s-Open-UAS/media/blob/main/Introduction%20to%20C%23%20programming/02-01-dotnet-architecture.png">

- [ ] .NET applications are written in C#, F# or Visual Basic.
- [ ] The application codes are compiled with respective compilers, resulting in programming language agnostic Common Intermediate Language `(CIL)`, stored as `.DLL` or `.EXE` files.
- [ ]  The **Common Language Runtime (CLR)** is responsible for running the applications and turning them in to machine code for the target architecture, using a **just-in-time compiler (JIT)**
- [ ]  thus making the foundation of the framework. The **CLR** can be thought as an agent which takes care of `execution time` `code management`, `memory management`, `thread management` and promotes `security` and `robustness`.

> The Framework Class Library `(FCL)` provides the core functionality of the framework.FCL is a collection of classes, namespaces, interfaces and value types for .NET applications. It can be used to develop applications such as console apps, Windows GUI applications (Windows Forms), Windows Presentation Foundation, ASP.NET applications, Windows services, Service-oriented applications using Windows Communication Foundation (WCF) and Workflow-enabled applications using Window Workflow Foundation (WF).

- Those users who want to run .NET Framework applications must have the .NET Framework Runtime installed on their computers. However, the user most likely will not have to make any effort regarding that, as for example, Windows 10 has .NET Framework 4 installed and enabled by default.
- Should the application require any specific version of the framework, the installer may already provide it. The framework resolves potential version conflicts by allowing multiple versions of the framework on the same computer. The .NET Framework is currently at version 4.8.0 (at the time of writing).

- The developers who want to make .Net Framework applications need to install the .NET Framework Developer Pack, which includes the specific version of the .Net Framework and Software Development Kit (SDK). In case you are using Visual Studio for development, you can benefit from the workload and component management which is integrated with the Visual Studio installer – adding and removing any components can be done directly from Visual Studio.

- .NET Framework is for Windows systems only. If you want to develop cross-platform applications which runs on Windows, MacOS and Linux, have a look at the .NET Core.
