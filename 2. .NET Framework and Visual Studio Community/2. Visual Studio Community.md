#### Visual Studio Community
- As you have learnt already, C# source code can be written with any text editor, as it is just a plain text file (or files).
- IDE’s like Visual Studio are often used with programming because they provide numerous features to make programming flow faster and more productive. Here are some features of an IDE:
    1. Advanced source code editor
    2. Project file management
    3. Syntax highlighting
    4. Auto-completion
    5. Build automation tools
    6. Debugging tools
    7. Source code control
    8. Quick access to help
- The downside using IDE is the complexity and learning curve especially for novice programmers. That effort is worthwhile in the long run, though. The choice of tools is up to you – if you feel more comfortable with a simple text editor at first, that is fine. On this course the examples are shown from Visual Studio Community’s user interface.

> (If you do not want to use an IDE on this course or have it already installed, you may skip the rest of the pages in this chapter.)
